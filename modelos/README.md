# Modelos reutilizáveis

Copie estes arquivos para uma pasta privada fora do clone antes de preencher:

- [Candidatura](candidatura.md): fatos, adequação à vaga e respostas em inglês.
- [História profissional](historia-profissional.md): contexto, ação, resultado e evidência.
- [Acompanhamento](acompanhamento.csv): abra em um editor ou importe em uma planilha.

Os campos entre colchetes são marcadores, não exemplos de fatos reais. Para o CSV,
selecione UTF-8 e vírgula como separador. Use datas no formato `AAAA-MM-DD`.
O arquivo tem apenas cabeçalhos, sem candidatos, recrutadores ou processos reais.

Preencher um arquivo já rastreado pelo Git pode expor suas informações no próximo
commit. O `.gitignore` não protege alterações em arquivos que já estão rastreados.
Não envie os modelos preenchidos em pull requests ou issues.
